# 주석 대신 이름으로 설명하라고 지시한다

## 요약

코딩 에이전트에게 **`설명은 코드 이름으로 합니다. 주석 없이 읽히게 씁니다.`** 한 줄을 넣으면
생성 코드의 추가 주석이 **133자 → 0자**(3/3 완전 준수), 테스트 통과율은 10/10 유지.
전체 코드량은 −5.7%지만 **압축 후 크기는 −15.9%** 다 — 걷힌 것이 반복 잉여가 아니라 내용이다.

**단, 기준 조건이 주석을 달지 않는 과제에서는 아무 효과가 없다.** 같은 지시가 라운드 6에서
기각됐던 이유가 이것이다(15시행 전부 추가 주석 0자). **먼저 재고 나서 건다.**

## 적용법

과제 명세 뒤, 꼬리 지시 앞에 한 줄로 넣는다. 실측에 사용한 문구 그대로:

```
설명은 코드 이름으로 합니다. 주석 없이 읽히게 씁니다.
```

**두 문장이 다 필요하다.** 앞 문장이 없으면 설명을 지우라는 뜻이 되고, 뒷 문장이 없으면
주석을 어디까지 줄일지가 열린다.

### 걸기 전에 기준 조건을 잰다

```
python experiments/scripts/score_r8.py   # cmt_add 열을 본다
```

지시 없이 2시행을 돌려 **추가 주석이 0자면 이 지시는 걸 자리가 없다.** 라운드 8은 이
파일럿 게이트를 사전등록해 두었고, 통과했기 때문에 본시행을 돌렸다.

| 과제 | 기준 조건 추가 주석 | 결과 |
|---|---|---|
| 41줄 할 일 목록 모듈에 함수 추가 (r6) | **0자** | 잴 것이 없어 판정 불가 |
| 29줄 영업일·기간 모듈, 규약 비자명 (r8) | **133자** | 지시가 표적을 맞힘 |

**차이는 파일 크기가 아니라 규약의 비자명성이다.** 주석이 붙은 자리는 여섯 시행 전부
같았다 — 반열림 구간 `[start, end)`, `n=0` 무보정, 음수 방향, 길이 0 구간 폐기.

### 쓰면 안 되는 경우

- **인수인계용 코드.** 통과 여부만 봤고 사람이 나중에 읽을 때의 비용은 재지 않았다
- **주석이 명세인 코드** (공개 API 문서 주석, 라이선스 헤더). 지시는 이를 구분하지 않는다
- 기준 조건 주석 밀도가 0인 과제

## 한계

1. **문자 수는 토큰이 아니다.** `usage.output_tokens` 없이는 확인 불가.
2. **코드량 −5.7%는 부호만 신뢰한다.** 조건 간 분포가 겹친다. 신뢰할 수 있는 것은
   **주석 항(133 → 0)** 이고 이쪽은 예외가 없다.
3. **품질을 테스트 통과로만 확인했다.** 주석 없는 코드가 리뷰·유지보수에 충분한지는
   재지 않았다. `bytes_gz` 가 −15.9%라는 것은 **실제 정보가 빠졌다**는 뜻이기도 하다.
4. **과제 1종·언어 1종(JS).** 타입 주석이 없는 언어라 이름만으로 담을 수 있는 정보가
   제한된다. 파이썬 독스트링·JSDoc 처럼 도구가 소비하는 주석은 미측정.
5. **기준 조건이 이미 오염돼 있다 → 절감은 하한.** 피험자가 저장소 억제 규칙을 물고 시작한다.
6. **다른 억제 지시와 함께 걸면 합만큼 나오지 않는다** (하위가산성 약 60~65%,
   `scope-limit-instruction.md` 참조).
