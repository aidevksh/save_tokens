# 데이터 대신 생성기를 낸다

## 요약

산출물이 알고리즘적으로 규칙적이면 데이터를 나열하는 대신 **그것을 만드는 코드**를 내게 한다. 규칙이 명시된 60행 CSV에서 **−95.3%**(2,160자 → 102자), 실행 대조 4/4 통과.

**규칙성이 낮으면 쓰지 않는다.** 불규칙 재료에서는 조건 평균 −17.1%에 그쳤고, 두 시행 중 하나는 나열보다 **더 길었다**.

## 적용법

출력 형식 지시를 데이터에서 프로그램으로 바꾼다.

```
**할 일**: 이 배치표 60행을 표준출력으로 찍는 파이썬 프로그램을 `out.py` 에
저장하세요. `python out.py` 로 실행하면 60줄이 정확히 그대로 나와야 합니다.
파일에는 프로그램만 넣고 설명이나 주석은 넣지 않습니다.
```

실측에서 나온 산출물 전문(98자):

```python
for i in range(60):
    print(f"shard-{i:03d},node-{i // 10}.example.com,{7000 + i},{i % 4 + 1}")
```

**쓸 조건.** 하나라도 어긋나면 쓰지 않는다.

| 조건 | 이유 |
|---|---|
| 규칙이 **명시돼 있다** | 규칙을 모델이 찾아내야 하면 결과가 갈린다 |
| 받는 쪽이 **실행할 수 있다** | 코드는 실행 환경을 요구한다. 사람이 눈으로 볼 산출물에는 못 쓴다 |
| **실행 대조를 붙인다** | 짧아도 틀리면 의미가 없다. 검증 없이 절감률을 말하지 않는다 |

**콜모고로프 복잡도의 직접 적용이다.** 대상의 복잡도는 그것을 출력하는 가장 짧은 프로그램의 길이다. 규칙 조건의 60행은 전부 `i`의 함수이므로 두 줄짜리 루프가 데이터 전체와 정보적으로 같다. 이 저장소의 다른 형식 기법(`tabular-payload-tsv-over-json.md`, `row-repeat-folding.md`, `prompt-codebook.md`)은 전부 "같은 데이터를 다른 표기로"인데, 이것만 **표현 층위**를 바꾼다.

## 한계

- **불규칙 재료에서는 결과가 두 배로 갈린다.** 두 시행이 1,373자와 2,118자였고, 후자는 60행을 삼중따옴표 문자열로 감싸 `print` 한 번 한 것이라 **나열(2,105자)보다 길었다.** 조건 평균 −17.1%는 이 분산을 감춘다.
- **완전 무작위 데이터는 미측정.** 이 실험의 불규칙 재료도 `shard_id`만은 인덱스의 함수라 부분적으로 규칙적이다. 역전은 시행 수준에서만 관측됐다.
- **소비자 실행 비용 미측정.** 코드를 받은 쪽의 실행 환경·시간·실패 위험을 재지 않았다.
- 수치는 **문자 수 proxy**다. 반복되는 CSV 행은 토크나이저가 이미 싸게 처리할 수 있어 실제 토큰 절감은 −95.3%보다 작을 수 있다 (A6-H7, 미판정).
- 재료 1종(60행 × 4필드 CSV), 언어 1종(파이썬)에서만 쟀다.
- **실행 결과의 줄바꿈에 주의.** 윈도 파이썬의 표준출력은 CRLF로 나간다. 실측에서 두 시행이 이를 스스로 보고했고, 채점은 줄바꿈을 정규화해 대조했다.
