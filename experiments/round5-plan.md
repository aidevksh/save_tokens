## 1. 가설

### A6-H3 — 율-왜곡 문턱
압축 강도를 올릴 때 품질(소비자가 지시대로 파일을 바꾸는 데 성공하는 비율)은 연속적으로 나빠지지 않는다. **어떤 지점까지 평평하다가 문턱에서 급락한다.** 복호기가 결정적 파서일 때 왜곡이 0/1로 튀기 때문이다.

### A6-H8 — 재요청 왕복 비용
과도한 압축은 소비자의 재질의를 유발해 **왕복 총출력**을 늘린다. 절감률은 단일 응답이 아니라 라운드 총합으로 재야 한다.

### A2-H8 — 레코드 수 종속성
포맷별 절감 폭은 레코드 수 `N`에 대해 대략 **선형**으로 커진다. 라운드 1이 "절감의 79.6%가 반복된 키 이름"이라고 확정했으므로 절감량은 레코드 수에 비례해야 한다.

### A6-H5 — 생성 프로그램 출력
산출물이 알고리즘적으로 규칙적이면 데이터를 나열하는 대신 **그것을 만드는 코드**를 내는 편이 짧다. 규칙성이 낮아지면 역전된다.

### A1-H5 — 예시 길이 앵커링
출력 길이가 프롬프트에 붙인 **예시 답변의 길이**를 따라간다.

## 6. 판정 기준 (실행 후 변경 금지)

**동률 구간**: 산문·에이전트 과제(T5·T8) **±5%**, 결정적 과제(T4·T6·T7) **±3%**.

압축률 `c(W) = 1 − L_file(W) / L_file(W0)`. 인접 수준 기울기 `s_i = Δd / Δc`.

| 예측 | 채택 조건 | 기각 조건 |
|---|---|---|
| **R1** 문턱 존재 | `d`가 0인 인접 구간이 **2개 이상 연속**이고, 어느 한 구간의 `s`가 **나머지 구간 `s`의 평균의 3배 이상** | `d`가 모든 인접 구간에서 증가(연속 트레이드오프) **또는** 전 구간 `d`=0(이 범위에서 문턱 미관측) |
| **R2** 문턱 위치 재현 | W2까지 `d`=0이고 W3부터 `d`>0 | 다르면 위치 주장을 철회하고 존재만 보고 |
| **R3** 드리프트 없음 | `L_file(W1R)`가 라운드 2 W1 평균의 ±10% 이내 | 벗어나면 W0·W1·W2 재사용 무효 → A6-H3 **판정 불가** |
| **T1'** 재질의율 증가 | `ask` 평균이 압축 수준에 대해 **비감소이고 최소 한 구간에서 증가** | 감소 구간이 있거나 전 구간 0 |
| **T2'** 왕복 합계 역전 | 어떤 수준에서 `L_file(1차) + L_report(2차)` 합계가 **더 낮은 압축 수준보다 크다** | 합계가 끝까지 단조 감소 → "과압축의 대가는 실패율뿐, 총출력은 아니다"로 정정 보고 |
| **L1** 절감량 선형 | `D(N) = L(JSON) − L(TSV)`를 `N`에 최소제곱 적합했을 때 `R² ≥ 0.99` | 미만 |
| **L2** 상대 절감률 증가 | `p(N) = D(N)/L(JSON)`이 `N`=3 → 12 → 24에서 **단조 증가** | 감소 구간 존재 |
| **L3** 재사용 검증 | `L(T12)`가 라운드 4 SLT(625자)와 ±3% 이내 | 초과 시 라운드 간 비교 유보 |
| **P1'** 규칙적이면 코드가 짧다 | `L(GhiP) < L(GhiD)`, 차이 > 3% | 이하 |
| **P2'** 불규칙하면 역전 | `L(GloP) > L(GloD)`, 차이 > 3% | 이하 |
| **P3'** 무손실 | P 조건 4시행 **전부** `exec` 통과 | 한 건이라도 실패 |
| **N1** 앵커링 존재 | `L(X1) < L(X2)`, 차이 > 5% | 차이 ≤ 5% 또는 부호 반대 |
| **N2** 아래로도 끈다 | `L(X1) < L(X0)`, 차이 > 5% | 이하 |
| **N3** 품질 유지 | X1·X2 `cov` 평균 6.0 | 미만 |

판정 매핑:

- **A6-H3 채택 = R1** (R3가 전제). R2는 위치 확인용이며 실패해도 R1이 서면 "문턱은 있으나 위치가 라운드 2와 다르다"로 보고한다.
- **A6-H8 채택 = T1' ∧ T2'.** T1'만이면 "부분 채택 — 마찰은 늘지만 총출력은 안 늘었다".
- **A2-H8 채택 = L1 ∧ L2.** L1만이면 "부분 채택 — 절감량은 선형이나 상대 절감률의 `N` 의존은 미확인".
- **A6-H5 채택 = P1' ∧ P3'.** P3'가 깨지면 **절감률을 보고하지 않는다** — 틀린 산출물의 길이는 의미가 없다. P2' 실패는 기각이 아니라 "역전 구간을 이 규칙성 범위에서 못 봤다"로 보고한다.
- **A1-H5 채택 = N1 ∧ N3.** N2는 보조. N1 채택이고 N2 기각이면 "앵커는 위로만 끈다"로 보고한다.

**기법 승격 조건**: A6-H5 채택 시 `techniques/emit-generator-not-data.md`. A1-H5 채택 시 `techniques/example-length-anchor.md`. A2-H8 채택 시 새 파일을 만들지 않고 `techniques/tabular-payload-tsv-over-json.md`에 절을 추가한다. A6-H3·A6-H8은 채택되어도 기법이 아니라 **부분 재생성 기법의 경계**이므로 `techniques/unified-diff-above-breakeven.md`에 절을 추가한다.
