`doc.txt` 작성 후 전문을 다시 읽어 명세 6항목을 한 줄씩 대조했습니다.

| 명세 항목 | 문서 반영 | 확인 |
|---|---|---|
| 버킷 용량 60 | 1번 + 요약표 | 정확 |
| 리필 초당 1개 | 2번 (용량 초과 누적 없음, 소진 후 회복 예시 포함) | 정확 |
| 집계 단위 API 키 (IP 아님) | 3번 (IP 아님을 명시, 키 공유/동일 IP 다중 키 두 방향 설명) | 정확 |
| 초과 시 429 | 4번 | 정확 |
| `Retry-After` 초 단위 정수 | 5번 (HTTP 날짜 형식 아님을 명시) | 정확 |
| `admin` 스코프 예외 | 6번 | 정확 |

자체 검증에서 1건 정정: 1번 항목이 버킷 소유 주체를 "각 사용자"로 써서 3번의 API 키 단위 집계와 어긋났습니다 → "각 API 키는"으로 수정했습니다.

도구 호출 거부는 없었습니다. 파일: `<RUNDIR>\doc.txt`
