| 명세 항목 | 명세 값 | 문서 반영 | 위치 |

| 버킷 용량 | 60 | 정확 | 2절 + 요약표 |

| 집계 단위 | API 키 (IP 아님) | 정확, "IP 아님"까지 명시 | 4절 + 요약표 |
| 초과 시 상태 코드 | 429 | 정확 | 5절 + 요약표 |
| 재시도 안내 헤더 | Retry-After (초 단위 정수) | 정확, 날짜 형식 아님까지 명시 | 6절 + 요약표 |
