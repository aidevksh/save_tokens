요청 제한(Rate Limit) 안내

우리 서비스는 토큰 버킷 방식으로 요청량을 제한합니다.

1. 버킷 용량 60
각 사용자는 토큰 60개가 담긴 통을 가집니다. 요청 1건마다 토큰 1개를 씁니다. 통이 비어 있지 않은 한 최대 60건까지 연속으로 보낼 수 있습니다.

2. 리필 속도 초당 1개
쓴 토큰은 1초에 1개씩 다시 채워집니다. 즉 평균적으로는 초당 1요청, 순간적으로는 최대 60요청까지 허용됩니다. 통이 가득 차면 더 쌓이지 않습니다.

3. 집계 단위: API 키
제한은 IP 주소가 아니라 API 키 단위로 셉니다. 한 서버에서 여러 키를 쓰면 통이 키마다 따로 있고, 여러 서버가 한 키를 공유하면 통도 하나입니다.

4. 초과 시 429
토큰이 없을 때 요청하면 HTTP 429(Too Many Requests)를 돌려줍니다.

5. Retry-After 헤더
429 응답에는 Retry-After 헤더가 붙습니다. 값은 몇 초 뒤에 재시도하면 되는지를 나타내는 정수입니다. 이 값만큼 기다렸다가 재시도하세요. 즉시 재시도하지 않습니다.

6. 예외: admin 스코프
admin 스코프를 가진 키는 제한 대상이 아닙니다. 토큰을 소모하지 않으며 429도 받지 않습니다. 일반 트래픽에 admin 키를 쓰지 마세요.
