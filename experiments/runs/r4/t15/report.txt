`doc.txt` 작성 완료.

- 경로: `<RUNDIR>/doc.txt`
- 구성: 토큰 버킷 개념 도입부 → 6개 항목 각각 절(節)로 설명 → 요약 표
- 6개 항목 모두 포함: 버킷 용량 60(버스트 의미), 리필 초당 1개(지속 평균 속도·60초 완충), 집계 단위 API 키(IP와의 차이가 실무에서 갖는 결과), 429(재시도 가능 신호로 다룰 것), `Retry-After` 초 단위 정수(예시 응답 + jitter·재시도 상한 지침), admin 스코프 예외(운영 키 오남용·부하 테스트 주의)
- 도구 호출 거부 없음.
