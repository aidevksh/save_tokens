요청 제한은 토큰 버킷 방식으로 동작한다.

버킷 용량은 60이다. 요청 1건이 토큰 1개를 쓴다. 버킷이 가득 찬 상태에서는 60건까지 연속 처리된다.

리필 속도는 초당 1개다. 소모된 토큰은 매초 1개씩 채워진다. 용량 60을 넘겨 쌓이지는 않는다.

집계 단위는 API 키다. IP 주소가 아니다. 같은 IP에서 서로 다른 키를 쓰면 버킷도 서로 다르다. 반대로 여러 서버가 같은 키를 쓰면 버킷을 공유한다.

토큰이 없는 상태에서 들어온 요청은 상태 코드 429로 거절된다.

429 응답에는 `Retry-After` 헤더가 붙는다. 값은 초 단위 정수다. 클라이언트는 그 초만큼 기다린 뒤 재시도한다. 예: `Retry-After: 5` 는 5초 후 재시도를 뜻한다.

`admin` 스코프 키는 제한에서 제외된다. 이 키의 요청은 토큰을 소모하지 않고 429도 받지 않는다.
