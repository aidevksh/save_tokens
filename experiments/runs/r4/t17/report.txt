## 수정 내역

| 함수 | 문제 | 수정 |
|---|---|---|
| `mean` | 정수 나눗셈 `//` 이라 소수 평균이 버려짐 (`[1,2]` → 1) | `/` 로 변경 |
| `median` | 정렬하지 않고 인덱싱, 짝수 길이 처리 없음 | `sorted()` 후 홀수는 중앙값, 짝수는 가운데 두 값 평균 |
| `mode` | 동점일 때 먼저 나온 값을 반환 (`[2,2,1,1]` → 2) | 동점이면 더 작은 값으로 교체하는 조건 추가 |
| `variance` | 코드는 정상, `mean` 의 정수 나눗셈 때문에 값이 틀렸음 | 별도 수정 없음 (`mean` 수정으로 해결) |
| `summary` | 정상 | 없음 |

부수 사항: `mode([])` 는 원래 코드대로 `None` 을 반환합니다(`counts` 가 비어 루프가 돌지 않음). 새로 넣은 `v < best` 비교는 `best_count == 0` 인 첫 항목에서는 `c > 0` 쪽이 먼저 참이 되므로 `best` 가 `None` 인 상태로 비교되는 일은 없습니다.
