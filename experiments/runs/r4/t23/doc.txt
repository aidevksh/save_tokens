요청 제한은 토큰 버킷 방식으로 동작한다. 아래 6개 항목이 전부다.

버킷 용량은 60이다. 버킷에 토큰이 최대 60개까지 쌓이므로 순간적으로 60회까지 요청할 수 있다.

리필 속도는 초당 1개다. 비워진 버킷은 60초가 지나면 다시 가득 찬다.

집계 단위는 API 키다. IP 주소가 아니므로 같은 IP에서 서로 다른 키를 쓰면 버킷도 따로 잡힌다.

초과 시 상태 코드는 429다. 버킷에 토큰이 없는 상태에서 들어온 요청은 429로 응답한다.

재시도 안내 헤더는 `Retry-After`다. 값은 초 단위 정수이며, 그만큼 기다린 뒤 다시 보내면 된다. 예: `Retry-After: 5`는 5초 후 재시도를 뜻한다.

예외는 `admin` 스코프 키다. 이 스코프를 가진 키는 제한에서 제외되어 429를 받지 않는다.
