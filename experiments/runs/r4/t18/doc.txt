요청 제한(rate limit) 동작 명세

버킷 용량은 60이다. 요청 하나가 토큰 하나를 쓴다. 버킷이 비면 더 못 쓴다.

리필 속도는 초당 1개다. 비워진 버킷은 초당 1개씩 다시 찬다. 최대 60까지만 찬다.

집계 단위는 API 키다. IP 주소가 아니다. 같은 IP에서 서로 다른 키로 보내면 각각 별도로 센다.

한도를 넘긴 요청은 상태 코드 429를 받는다.

429 응답에는 `Retry-After` 헤더가 붙는다. 값은 초 단위 정수다. 그 초만큼 기다린 뒤 다시 보내면 된다.

예외가 하나 있다. `admin` 스코프 키는 제한에서 제외된다. 이 키의 요청은 버킷과 무관하게 처리된다.

예시: 어떤 키가 1초 안에 61번 요청하면 앞의 60번은 통과하고 61번째는 429와 `Retry-After: 1`을 받는다.
