`doc.txt` 작성 완료.

- 위치: `<RUNDIR>/doc.txt`
- 구성: 토큰 버킷 개념 도입부 → 6개 항목 각각 절로 설명(용량 60 / 초당 1개 리필 / API 키 단위 / 429 / `Retry-After` 정수 초 / `admin` 스코프 제외) → 클라이언트 구현 체크리스트
- 신입 개발자가 오해하기 쉬운 지점을 각 절에 붙였습니다: 버스트 60건과 지속 처리량 초당 1건의 구분, 같은 키를 쓰는 다중 인스턴스는 버킷을 공유하므로 서버 증설로 처리량이 늘지 않음, 429는 요청 내용 오류가 아니므로 4xx 일괄 실패 처리 금지, `Retry-After`는 HTTP-date가 아닌 정수 초, admin 키로 테스트하면 429 경로가 검증되지 않음.
- 도구 호출 거부 없었습니다.
