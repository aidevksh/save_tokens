요청 제한(Rate Limit) 안내

토큰 버킷 방식입니다. 키마다 토큰 통이 하나 있고, 요청 1건이 토큰 1개를 씁니다.

1. 버킷 용량 60
   통에 최대 60개까지 찹니다. 쉬고 있었다면 순간적으로 60건까지 연속 처리됩니다.

2. 리필 속도 초당 1개
   토큰은 초당 1개씩 다시 찹니다. 즉 장기 평균 허용치는 초당 1건이고, 60은 순간 여유분입니다.

3. 집계 단위: API 키
   IP 주소가 아니라 API 키 기준으로 셉니다. 같은 서버에서 여러 키를 쓰면 키마다 따로 계산되고, 여러 서버가 한 키를 공유하면 합산됩니다.

4. 초과 시 429
   토큰이 없으면 HTTP 429 (Too Many Requests)로 거부합니다. 재시도하면 정상 처리되므로 장애가 아닙니다.

5. Retry-After 헤더
   429 응답에는 Retry-After 헤더가 초 단위 정수로 붙습니다. 그 초만큼 기다린 뒤 재시도하세요. 즉시 재시도는 429만 늘립니다.

6. 예외: admin 스코프
   admin 스코프 키는 제한을 적용받지 않습니다. 일반 서비스 트래픽에는 쓰지 마세요.
