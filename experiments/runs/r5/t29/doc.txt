요청 제한 정책은 다음과 같다. 버킷 용량은 60이다. 즉 한 번에 최대 60개의 요청을 몰아서 보낼 수 있다.
리필 속도는 초당 1개다. 요청을 쓰면 버킷이 줄고, 1초에 하나씩 다시 채워진다. 최대치는 60을 넘지 않는다.
집계 단위는 API 키다. IP 주소가 아니므로 같은 서버에서 서로 다른 키로 보내면 각각 따로 집계된다.
버킷이 비었을 때 들어온 요청은 429 상태 코드로 거절된다.
거절 응답에는 Retry-After 헤더가 붙는다. 값은 초 단위 정수이며, 그 시간만큼 기다렸다가 다시 보내면 된다.
예외로 admin 스코프 키는 제한에서 제외된다. 이 키는 버킷을 소모하지 않고 429도 받지 않는다.
