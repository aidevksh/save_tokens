## 요구사항 충돌 보고

"컨텍스트 줄 없음"과 "`git apply -p1` 로 적용 가능" 두 조건은 동시에 만족할 수 없다. 원본을 복제해 직접 검증했다.

| 명령 | 결과 |
|---|---|
| `git apply -p1 --check` | **실패** — `error: patch failed: deploy.yaml:13` / `patch does not apply` (exit 1) |
| `git apply -p1 --unidiff-zero --check` | 성공 (exit 0) |
| `git apply -p1 --unidiff-zero` 실제 적용 | 성공, 6곳 모두 의도대로 반영 확인 |

`git apply`는 컨텍스트 0줄 diff를 기본적으로 거부한다(줄 위치를 검증할 근거가 없어 오적용 위험이 있기 때문). 지시대로 컨텍스트를 넣지 않은 형태로 저장했으므로, 적용 시 `--unidiff-zero` 를 붙여야 한다. 플래그 없이 적용해야 한다면 컨텍스트 줄을 최소 1줄 넣은 형태로 다시 만들어야 한다.

도구 호출 거부는 없었다.
