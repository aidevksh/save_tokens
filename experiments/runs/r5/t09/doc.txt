요청 제한(rate limit) 동작은 다음과 같다. 버킷 용량은 60이다. 즉 한 번에 최대 60개의 요청을 몰아서 보낼 수 있다.
리필 속도는 초당 1개다. 소모한 버킷은 1초에 1개씩 다시 채워지며, 최대 60까지만 쌓인다.
집계 단위는 API 키다. IP 주소가 아니므로 같은 서버에서 여러 키를 쓰면 키마다 따로 계산되고, 여러 IP에서 같은 키를 쓰면 합산된다.
초과 시 상태 코드는 429다. 버킷이 비면 요청은 처리되지 않고 429가 돌아온다.
재시도 안내 헤더는 Retry-After다. 초 단위 정수로 담기며, 그 초만큼 기다린 뒤 다시 요청하면 된다.
예외는 admin 스코프 키다. admin 스코프를 가진 키는 제한에서 제외되어 429를 받지 않는다.
