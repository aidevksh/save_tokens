신입 백엔드 개발자용 요청 제한 설명 문서를 `doc.txt`에 작성했습니다.

구성: 참고 문서와 같은 형식(제목 + 도입 문단 + 번호 매긴 항목별 섹션)을 따라 6개 항목을 모두 다뤘습니다.

1. 버킷 용량 60 — 토큰 버킷 비유, 버스트 최대 60건
2. 리필 속도 초당 1개 — 장기 평균 초당 1건, 버스트 완전 회복에 60초
3. 집계 단위 API 키 — IP가 아님을 명시하고, 같은 키를 여러 서버에 심으면 양동이를 공유하므로 서버 증설로 우회 불가하다는 실무 함의 추가
4. 429 — 코드 오류가 아니라 시점 문제라는 점 강조
5. `Retry-After` — 초 단위 정수, 헤더 값 준수 및 백오프 권장
6. `admin` 스코프 예외 — 예외의 목적과 일반 트래픽에 쓰면 안 되는 이유

파일: `<RUNDIR>/doc.txt`
