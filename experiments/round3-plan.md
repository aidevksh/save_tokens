# 라운드 3 사전등록 — 프롬프트 지시문 요인 분해 + 마크다운 표 비용

작성 시각: 데이터 수집 **전**. §6 판정 기준은 실행 후 변경하지 않는다.

라운드 1은 프롬프트 억제 지시를 **묶음**으로 시험했고 하네스 차단으로 판정 불가가 됐다(A5-H7). 라운드 3은 묶음을 풀어 요인 하나씩 본다. 동시에 라운드 1에서 채택된 A2-H1(JSON→TSV)의 경계를 확인한다 — 마크다운 표는 TSV와 JSON 사이 어디인가.

## 1. 가설

### A1-H6 / A5-H2 — 검증 지시 제거 (두 축이 같은 주장)
과잉 검증을 유발하는 지시를 제거하면 품질 손실 없이 출력이 준다. 공식 문서가 유일하게 "토큰 감소 + 품질 손실 없음"을 명시한 항목이고 라운드 1에서 "가장 아까운 탈락"으로 기록됐다.

### A1-H1 — 긍정형 vs 부정형 간결성 지시
간결성 지시가 출력을 줄이고, **긍정형("핵심만 쓰세요")이 부정형("장황하게 쓰지 마세요")보다 감소 폭이 크다.**

### A1-H7 — 프롬프트 마크다운 제거
지시문을 평문 산문으로 주면 출력의 **마크업 비율과 길이가 함께** 준다. 모델이 프롬프트의 서식을 모방한다는 가정.

### A2-H6 — 마크다운 표 비용
마크다운 표는 같은 정보의 TSV보다 길고, 증가분은 레코드 수에 비례한다. A2-H1이 확정한 "절감의 79.6%가 반복된 키 이름"이 맞다면 마크다운 표는 키를 한 번만 쓰므로 **JSON보다 훨씬 짧고 TSV보다 약간 길어야** 한다 — 즉 증가분은 파이프·정렬 공백에서만 온다.

## 2. 설계

과제 2개, 조건 7개, 19시행.

### 과제 T1 — 산문 설명 문서 (A1-H6 / A1-H1 / A1-H7)

요청 제한 명세 6항목을 신입 개발자용 설명 문서로 쓴다. 산출물 `doc.txt`.
자유 서술 과제라 **조건 내 분산이 0이 아니다** → n=3. (라운드 1 교훈은 결정적 과제에 한정된다.)

| 조건 | 처치 | 시행 |
|---|---|---|
| **B** | 없음 (기준) | t01, t09, t16 |
| **N** | 부정형 간결성 지시 (48자) | t02, t08, t18 |
| **P** | 긍정형 간결성 지시 (48자) | t04, t10, t15 |
| **V** | 검증 지시 추가 (70자) | t05, t12, t17 |
| **F** | 프롬프트를 평문 산문으로 (본문 명제 동일) | t06, t11, t19 |

N과 P는 **같은 3개 명제의 극성만 바꾼 것**이고 길이가 48자로 동일하다(생성기 검증). B/N/P/V의 프롬프트는 처치 문단을 빼면 공백 정규화 후 바이트 동일하다(생성기 검증).

**A1-H6의 처치 방향에 주의**: 가설은 "제거하면 준다"인데 무처치 B에는 검증 지시가 없다. 그래서 **V를 검증 지시 있는 조건으로 만들고 B를 제거된 조건으로 둔다.** 제거 효과 = `L(B) − L(V)`.

### 과제 T2 — 표 직렬화 (A2-H6)

라운드 1 H1과 **동일한** 티켓 12건 × 8필드 추출. 프롬프트 공통부를 `r1-H1-A.txt`에서 파일째로 가져와 재사용한다(sha1 `bf627e2eba2e`). 결정적 과제 → n=2 겸 결정성 파일럿.

| 조건 | 출력 형식 | 시행 |
|---|---|---|
| **T** | 헤더 TSV (라운드 1 H1-B 복제) | t03, t13 |
| **M** | 마크다운 표 | t07, t14 |

양 조건 모두 `out.txt`에 쓴다 — 라운드 1에서 확장자별 하네스 차단이 **차등 탈락**을 만든 사건이 있었으므로 확장자를 통일해 그 경로를 막는다.

### 시행 순서

t01–t19에 조건을 뭉치지 않게 배치했다(위 표). 순서 효과는 서브에이전트가 독립 컨텍스트라 원리적으로 없지만, 하네스 상태 변화(차단 정책 등)가 조건에 편향되지 않게 한다.

## 3. 피험자 프롬프트

전문은 `experiments/prompts/r3-{B,N,P,V,F,T,M}.txt`. 생성기 `experiments/scripts/gen_r3_prompts.py`가 공통부를 한 곳에서 만든다 — 손으로 쓰면 의도치 않은 문구 차이가 섞인다.

전 조건 공통 꼬리(라운드 1b 교훈 선반영, 조작 변수 아님):
> 도구 호출이 거부되면 다른 수단으로 우회하지 말고, 거부되었다는 사실을 보고하고 중단합니다.

> 문서는 한국어로 작성합니다.

**naive 유지**: 토큰·길이·실험·조건을 언급하지 않는다. 시행 디렉터리는 저장소 밖(`scratchpad/st-r3/`). 산출물 파일명에 `summary`·`report`를 쓰지 않고 확장자는 `.txt`로 고정한다.

## 4. 종속 변수

| 기호 | 정의 | 측정 |
|---|---|---|
| `L_file` | 산출물 파일 문자 수 **(proxy)** — 주 지표 | `tools/measure.py` |
| `L_report` | 피험자가 대화로 돌려준 최종 보고 문자 수 **(proxy)** | 오케스트레이터가 `report.txt`로 기록 |
| `cov` | T1 명세 6항목 커버리지 (0–6) | 정규식, `score_r3.py` |
| `markup` | T1 산출물의 마크다운 구조 문자 비율 | `#`·목록머리·`|`·`**`·백틱 문자 / 전체 |
| `acc` | T2 셀 정확도 (96셀) | 정답 키 대조 |
| `hangul/latin` | 산문 언어 구성 | `tools/measure.py` |

`L_file`, `L_report`는 **문자 수이지 토큰이 아니다.** 조건 간 상대 비율로만 해석한다.

`L_report`를 따로 재는 이유: 검증 지시(V)의 비용은 파일이 아니라 대화 쪽에 실릴 수 있다. 파일만 재면 그 비용이 보이지 않는다.

## 5. 품질 게이트

게이트를 통과하지 못한 시행은 길이 집계에서 **제외**한다.

### T1 (B/N/P/V/F)

| 게이트 | 내용 |
|---|---|
| Q1 | `doc.txt` 존재, 크기 > 0 |
| Q2 | 산문 언어 구성 한국어 — 산문부 한글 음절 > ASCII 영문자 |
| Q3 | `cov == 6` (6항목 전부 서술) |

커버리지 정규식(사전 고정):

| 항목 | 패턴 |
|---|---|
| 용량 60 | `\b60\b` |
| 리필 초당 1 | `초당\s*1` \| `1\s*(개|회|토큰)\s*/?\s*초` \| `초에\s*1` \| `1초에\s*(1|한)` |
| API 키 단위 | `API\s*키` **and** `IP` |
| 상태 코드 | `\b429\b` |
| 헤더 | `Retry-?After` (대소문자 무시) |
| admin 예외 | `admin` **and** (`제외|면제|적용되지\s*않|예외|우회`) |

### T2 (T/M)

| 게이트 | 내용 |
|---|---|
| Q1 | `out.txt` 존재, 크기 > 0 |
| Q2 | 형식 준수 — T: 13줄·탭 구분·8열 / M: 파이프 구분·헤더+구분행+12행·8열 |
| Q3 | `acc ≥ 0.95` (96셀 기준) |

무효 사유는 Q1 실패(산출물 미생성)뿐이다. 조건별 무효 건수를 반드시 보고한다. 하네스 차단으로 산출물이 안 나온 경우는 **차단 사건으로 별도 기록**하고 조건별 차단 건수를 대조한다 — 라운드 1 A5-H7이 이걸 놓쳐 판정 불가가 됐다.

## 6. 판정 기준 (실행 후 변경 금지)

**동률 구간**: T1(산문, 분산 있음) **±5%**, T2(결정적) **±3%**. 동률이면 "차이 없음"으로 판정한다.

| 예측 | 채택 조건 | 기각 조건 |
|---|---|---|
| **P1** 검증 지시 비용 | `L_file(B) < L_file(V)` 차이 > 5% | `L_file(B) ≥ L_file(V)` 또는 차이 ≤ 5% |
| **P1q** 품질 무손실 | `cov(B) ≥ cov(V)` (평균) | `cov(B) < cov(V)` |
| **P2** 간결성 지시가 듣는다 | `L_file(N) < L_file(B)` **그리고** `L_file(P) < L_file(B)`, 둘 다 차이 > 5% | 둘 중 하나라도 미충족 |
| **P3** 긍정형 우위 | `L_file(P) < L_file(N)` 차이 > 5% | `L_file(N) < L_file(P)` 차이 > 5% |
| **P4** 마크업 전이 | `markup(F) < markup(B)`, 상대 차이 > 5% | `markup(F) ≥ markup(B)` |
| **P5** 길이 전이 | `L_file(F) < L_file(B)` 차이 > 5% | `L_file(F) ≥ L_file(B)` |
| **P6** 마크다운 표 비용 | `L(M) > L(T)` 차이 > 3% | `L(M) ≤ L(T)` |
| **P7** JSON보다 짧다 | `L(M) < L(라운드1 H1-A JSON)` | `L(M) ≥ L(JSON)` |
| **P8** 복제 | `L(T)`가 라운드 1 H1-B 산출물과 ±3% 이내 | 초과 |

판정 매핑:

- **A1-H6 / A5-H2 채택 = P1 ∧ P1q.** P1만 성립하면 "채택(절감 확인) — 단 품질 무손실은 미확인".
- **A1-H1 채택 = P2 ∧ P3.** P2가 기각이면 A1-H1은 **판정 불가**가 아니라 기각이다(전제가 무너지면 극성 비교는 무의미). P2만 성립하면 "부분 채택 — 간결성 지시는 듣지만 극성은 무관".
- **A1-H7 채택 = P4 ∧ P5.** P4만 성립하면 "부분 채택 — 서식은 옮겨오지만 길이는 안 줄어든다".
- **A2-H6 채택 = P6.** P7·P8은 해석 보조(P8 실패 시 라운드 간 비교 전체를 유보한다).

조건당 유효 시행이 T1 2건 / T2 2건 미만이면 그 조건이 관여하는 예측은 **판정 불가**다. 판정 불가를 채택으로 바꿔 쓰지 않는다.

**기법 승격 조건**: P1∧P1q 채택 시 `techniques/drop-self-verification-instruction.md`. P6 채택 시 A2-H1 기법 문서에 경계 절을 추가한다(새 파일을 만들지 않는다 — 같은 기법의 경계다).

## 7. 이 라운드가 만들 수 없는 주장

- 절대 토큰 절감률 (proxy 측정)
- **무오염 baseline 대비 절감률.** 이 저장소 `CLAUDE.md`의 응답 규칙("결론부터, 서론·자평 금지")이 서브에이전트 시스템 프롬프트에 상수로 걸린다. 조건 B는 **이미 억제가 걸린 baseline**이므로 P2·P5의 절감률은 **하한**이다. 진짜 무처치 대비 절감은 API로만 잴 수 있다(라운드 1 §7)
- A1-H4(서론·자평 억제 단독)에 대한 어떤 주장. 처치가 위 오염과 동일해 바닥 효과가 예상되어 **의도적으로 제외**했다
- A1-H1의 결론을 다른 명제 집합으로 외삽. 극성을 3개 명제에서만 뒤집었다
- A1-H7에서 프롬프트 길이와 서식의 분리. 서식을 없애면 길이가 −37자 줄고, 이 교란은 처치에 내재한다
- A2-H6의 레코드 수 비례성. 레코드 수를 12건 하나로 고정했다 → A2-H8은 여전히 미판정
- 산문 과제 1종·표 과제 1종 밖으로의 일반화
