## 1. 가설

### A6-H1 — 엔트로피 바닥
절감 지시를 누적해도 산출물 길이는 과제 고유의 하한으로 점근한다. **k번째 지시의 한계 절감은 단조 감소**하고, 압축 후 크기(`bytes_gz`) 기준 절감은 문자 기준 절감보다 **항상 작다**(줄어드는 것의 일부는 잉여이지 내용이 아니므로).

### A6-H2 — 상호정보량 제거
입력에서 결정적으로 복원 가능한 부분(요청 재진술, 파일 내용 인용)은 정보량이 0이다. 이것만 겨냥한 지시 한 줄이 **품질 손실 없이** 대화 보고문을 줄이고, 그 절감이 파일 쪽으로 재배분되지 않는다.

### A6-H4 — 대칭성 접기
행 방향 반복을 `^`로 접으면 헤더 TSV보다 짧다. 단 반복률이 낮으면 역전된다.

### A6-H6 — 코드북 상각
프롬프트에 코드북(1자 열 이름 + 정수 enum)을 선언하면 출력이 준다. 출력 회계에서는 언제나 이득이고, 총비용 회계에서만 재사용 횟수 손익분기 `R*`가 필요하다.

## 2. 설계

과제 3개, 조건 11개, **신규 23시행** + 라운드 3 재사용 6시행.

프롬프트 전문은 `experiments/prompts/r4-*.txt`. 생성기 `experiments/scripts/gen_r4.py`가 공통부를 한 곳에서 만들고 다음을 스스로 검증한다 — 실패하면 파일을 쓰지 않는다.

- T1 처치 줄 3개가 **각 48자로 동일** (지시 *길이*가 아니라 *개수*의 효과를 보려면 필요)
- 각 과제 안에서 처치를 뺀 공통부가 바이트 동일
- `r4-K0.txt` == `r3-B.txt`, `r4-K1.txt` == `r3-P.txt` (재사용 전제)
- T3 재료의 행 방향 반복률이 목표값과 일치

### 과제 T1 — 산문 설명 문서 (A6-H1)

라운드 3 T1과 동일한 요청 제한 명세 6항목. 산출물 `doc.txt`. 자유 서술이라 분산이 0이 아니다 → n=3.

지시를 **얹기만** 하고 앞 지시는 수정하지 않는다.

| 조건 | 처치 (누적) | 시행 |
|---|---|---|
| **K0** | 없음 | 라운드 3 t01·t09·t16 재사용 |
| **K1** | + 간결성 48자 | 라운드 3 t04·t10·t15 재사용 |
| **K2** | + 범위 축소 48자 | t01, t08, t18 |
| **K3** | + 수치 상한 48자 | t04, t12, t23 |
| **K0R** | 없음 (드리프트 확인 전용) | t15 |

처치 줄:
1. `핵심만 간결히 쓰세요. 본문부터 시작해 본문으로 끝내세요. 각 내용은 한 번만 쓰세요.`
2. `설명은 명세에 있는 사실로만 쓰세요. 예시는 하나까지만 쓰세요. 문장은 짧게 끊으세요.`
3. `각 항목은 두 문장 이내로 쓰세요. 표현은 평서문으로 쓰세요. 수식어는 하나만 쓰세요.`

셋 다 긍정형이고 각 48자다. 극성과 길이를 고정했으므로 조건 간 차이는 **명제 개수**뿐이다.

### 과제 T2 — 버그 수정 루프 (A6-H2)

`experiments/fixtures/task-a-bugfix`를 시행 디렉터리로 복사. `python -m unittest` 11건 중 **6건 실패** 상태에서 시작한다(정수 나눗셈, 미정렬 median, 짝수 길이 median, mode 동률·빈 입력, variance).

라운드 3이 산문 과제였던 것과 달리 **도구 호출이 도는 루프**다 — 공식 문서의 절감 주장이 겨냥한 사정거리이며, 라운드 3에서 대화 보고문이 파일 절감을 통째로 상쇄한 사건을 여기서 다시 본다.

| 조건 | 처치 | 시행 |
|---|---|---|
| **B2** | 없음 | t02, t09, t17 |
| **X2** | + `보고에는 새로 알게 된 것만 적습니다. 요청 내용과 파일 내용은 읽는 사람이 이미 가지고 있습니다.` | t05, t13, t20 |

처치는 **간결성 지시가 아니다.** 짧게 쓰라는 말이 없고 "무엇이 이미 상대에게 있는가"만 말한다. 간결성 지시로 읽히면 A1-H1의 재시험이 되어 버린다.

### 과제 T3 — 표 직렬화 (A6-H4, A6-H6)

서버 자산 12건 × 8필드 = 96셀. 재료는 생성기가 행 방향 반복률 `r`을 조작해 결정적으로 만든다(난수 없음).

- `r = 0.195` (77칸 중 15칸 반복) — 정답 키 `experiments/data/r4-assets-lo.tsv`
- `r = 0.805` (77칸 중 62칸 반복) — 정답 키 `experiments/data/r4-assets-hi.tsv`

두 재료의 프롬프트 길이는 1,482자 대 1,486자로 4자 차이다.

| 조건 | 재료 | 출력 형식 | 시행 |
|---|---|---|---|
| **SLT** | lo | 헤더 TSV | t03, t14 |
| **SLF** | lo | 접기 (`^`) | t06, t16 |
| **SHT** | hi | 헤더 TSV | t07, t19 |
| **SHF** | hi | 접기 (`^`) | t10, t21 |
| **CB** | lo | 코드북 (1자 열 이름 + 정수 enum) | t11, t22 |

**SLT는 A6-H6의 대조군을 겸한다** — CB와 프롬프트 공통부가 바이트 동일하고 형식 지시만 다르다.

코드북 선언이 프롬프트에 더한 문자 수 `ΔP = 329자` (생성기 산출, 사전 고정).

결정적 과제 → n=2 겸 결정성 파일럿. 라운드 2가 "결정성은 과제 유형이 아니라 출력 명세의 자유도가 정한다"고 정정했으므로, 접기 조건(`^` 판단이 열려 있다)에서 분산이 나올 수 있다. 나오면 그 자체를 보고한다.

**T2의 `pass`와 T3의 `acc`는 게이트가 아니라 결과 변수다.** 둘 다 판정 대상(M3, Y3, B2q)이므로 탈락 사유로 쓰면 가설의 실패를 데이터에서 지우게 된다. 원안에서 바꾼 지점이다(§0).

하네스 차단으로 산출물이 안 나온 경우는 **차단 사건으로 별도 기록**하고 조건별 차단 건수를 대조한다. 라운드 1 A5-H7이 이걸 놓쳐 판정 불가가 됐다.

조건당 유효 시행이 T1 2건 / T2 2건 / T3 1건 미만이면 그 조건이 관여하는 예측은 **판정 불가**다.

## 6. 판정 기준 (실행 후 변경 금지)

**동률 구간**: T1·T2(분산 있음) **±5%**, T3(결정적) **±3%**. 동률이면 "차이 없음"으로 판정한다.

`Δk` = 조건 K(k−1) 대비 Kk의 평균 문자 감소량(양수 = 줄었다). `%ΔL`, `%ΔG` = K0 대비 누적 상대 변화.

| 예측 | 채택 조건 | 기각 조건 |
|---|---|---|
| **E1** 한계 절감 체감 | `Δ1 > Δ2 > Δ3` **그리고** `Δ3 ≤ Δ1/2` | 어느 구간에서든 한계 절감이 증가 (`Δ2 > Δ1` 또는 `Δ3 > Δ2`) |
| **E2** 압축 후 절감이 더 작다 | K1·K2·K3 **전부**에서 `\|%ΔG\| < \|%ΔL\|` | 한 조건이라도 `\|%ΔG\| ≥ \|%ΔL\|` |
| **E3** 라운드 간 드리프트 없음 | `L(K0R)`가 구간 **[1610, 3304]** 안 (라운드 3 B 관측범위 2013–2753을 20% 넓힌 것) | 벗어나면 K0·K1 재사용 무효 → A6-H1 **판정 불가** |
| **E4** 품질 유지 | 전 조건 `cov == 6` 평균 | 어느 조건이든 평균 6 미만이면 그 조건 이후 절감은 "품질 대가 있음"으로 병기 |
| **M1** 보고문 절감 | `L_report(X2) < L_report(B2)`, 차이 > 5% | 차이 ≤ 5% 또는 부호 반대 |
| **M2** 재진술이 줄어서다 | `ncd(X2) > ncd(B2)` | 이하 — 길이는 줄었으나 **내용을 잘라낸 것** |
| **M3** 품질 무손실 | `pass(X2) ≥ pass(B2)` (평균) | 미만 |
| **M4** 풍선효과 없음 | `L_report(X2)+L_diff(X2) < L_report(B2)+L_diff(B2)`, 차이 > 5% | 차이 ≤ 5% → 라운드 3처럼 **재배분**일 뿐 |
| **Y1** 고반복에서 접기 승 | `L(SHF) < L(SHT)`, 차이 > 3% | 차이 ≤ 3% 또는 부호 반대 |
| **Y2** 저반복에서 역전 | `L(SLF) > L(SLT)`, 차이 > 3% | 이하 |
| **Y3** 접기 정확도 유지 | `acc(SHF) ≥ 0.95` **그리고** `acc(SLF) ≥ 0.95` | 어느 쪽이든 미만 |
| **B1** 코드북 출력 절감 | `L(CB) < L(SLT)`, 차이 > 3% | 이하 |
| **B2q** 코드북 정확도 유지 | `acc(CB) ≥ 0.95` (디코드 후) | 미만 |

판정 매핑:

- **A6-H1 채택 = E1 ∧ E2** (E3가 전제). E1만이면 "부분 채택 — 체감은 있으나 잉여/내용 분해 미확인". E2만이면 "부분 채택 — 절감의 상당분이 잉여지만 바닥은 미확인".
- **A6-H2 채택 = M1 ∧ M3 ∧ M4.** M2는 해석 보조이며 **단독 채택 근거로 쓰지 않는다**(보고문이 짧아지면 NCD가 그 자체로 오를 수 있다). M1 ∧ M3 이면서 M4 기각이면 "기각 — 재배분"으로 판정한다.
- **A6-H4 채택 = Y1 ∧ Y3.** Y2 실패는 기각이 아니라 "손익분기가 `r=0.195`보다 아래" 보고이며, 그 경우 **더 낮은 `r`로 재확인하기 전에는 "역전 없음"을 주장하지 않는다**.
- **A6-H6 채택 = B1 ∧ B2q.** `R* = ceil(ΔP / (L(SLT) − L(CB)))`는 판정 대상이 아니라 산출물이다. **출력 회계와 총비용 회계를 섞어 하나의 절감률로 보고하지 않는다.**

**기법 승격 조건**: A6-H4 채택 시 `techniques/row-repeat-folding.md`. A6-H6 채택 시 `techniques/prompt-codebook.md`. A6-H2 채택 시 `techniques/drop-input-restatement.md`. A6-H1은 채택되어도 기법이 아니라 **다른 기법의 한계 서술**이므로 새 파일을 만들지 않고 `techniques/positive-conciseness-instruction.md`에 절을 추가한다.

## 7. 이 라운드가 만들 수 없는 주장

- 절대 토큰 절감률 (proxy 측정). `bytes_gz`도 토큰이 아니다 — gzip은 토크나이저가 아니다
- **무오염 baseline 대비 절감률.** 피험 서브에이전트가 저장소 `CLAUDE.md`의 억제 규칙을 물고 시작한다. K0/B2는 이미 억제가 걸린 baseline이므로 모든 절감률은 **하한**이다
- 엔트로피 하한의 **값**. E1은 하한의 존재(체감)만 잰다
- A6-H1 결론의 지시 순서 일반화. 누적 순서를 하나로 고정했다 — 순서를 바꾸면 `Δk`가 달라질 수 있다
- A6-H4의 손익분기 반복률 `r*`. `r`을 두 점(0.195, 0.805)에서만 봤다
- A6-H6의 총비용 손익분기 `R*`의 실측. `ΔP`는 문자 수이고 입력 토큰 단가는 이 환경에서 알 수 없다
- A6-H2의 도구 호출 토큰. 서브에이전트의 도구 호출 인자는 계측할 수 없다 → `L_diff`는 그 하한
- 과제 3종 밖으로의 일반화
