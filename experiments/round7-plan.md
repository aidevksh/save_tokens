# 라운드 7 사전등록 — 미검증 가설 5건 (축 2 스키마 사다리 + 축 1 지시 요인·위치)

작성 시각: 데이터 수집 **전**. §5 판정 기준은 실행 후 변경하지 않는다.

축 2는 로컬에서 잴 수 있는 5건 중 3건(A2-H2·A2-H3·A2-H5)이 아직 미검증이다. 셋 다 "같은 표를 더
줄여서 내면 정확도가 얼마나 깎이는가"라는 하나의 사다리 위에 있으므로 한 과제로 묶어 본다.
축 1은 이미 채택된 긍정형 간결성 지시(−69.3%)의 **안을 연다** — 세 명제 중 무엇이 일하는가(A1-H4),
그리고 그 지시를 프롬프트 어디에 놓는가(A1-H2).

| 가설 | 축 | 주장 |
|---|---|---|
| **A2-H2** 키 축약 | 2 | 1글자 축약 키는 길이를 줄이지만 셀 정확도가 낮아진다 |
| **A2-H3** enum 코드화 | 2 | enum 정수 코드화는 길이를 줄이고 정확도 손실은 키 축약보다 작다 |
| **A2-H5** positional 출력 | 2 | 헤더 제거+코드화는 더 줄지만 레코드 정확도가 가장 크게 하락한다 |
| **A1-H4** 서론·자평 억제 | 1 | 서론·맺음말·자평 억제가 품질 유지하며 줄인다 |
| **A1-H2** 말미 리마인더 배치 | 1 | 긴 프롬프트에서 앞부분만보다 앞+말미 리마인더가 더 줄인다 |

| 항목 | 원안 | 이번 라운드 | 이유 |

## 1. 설계

과제 4개, 조건 15개, **신규 35시행**(t01–t35) + 라운드 4 재사용 8시행.

프롬프트 전문은 `experiments/prompts/r7-*.txt`. 생성기 `experiments/scripts/gen_r7.py` 가 다음을
검증한다 — 실패하면 파일을 쓰지 않는다.

- T11 네 조건이 출력 형식 문단을 뺀 공통부에서 바이트 동일
- `r7-T.txt` == `r4-SLT.txt` (sha1 `911fb5a91fb8`), `r7-C0.txt` == `r4-K0.txt` (`d807c63774cc`),
  `r7-CK.txt` == `r4-K1.txt` (`1772fcc5e03d`) — 재사용 전제
- T13 의 세 처치 줄을 이으면 CK 처치 줄과 바이트 동일
- T14 네 조건이 지시 줄을 뺀 공통부에서 바이트 동일
- 재료 12건이 정답 키 `experiments/data/r4-assets-lo.tsv` 와 바이트 동일

### 과제 T11 — 표 스키마 사다리 (A2-H2 / A2-H3 / A2-H5)

라운드 1·4와 같은 12레코드 × 8필드 서버 자산 대장(저반복 재료). 출력 형식 문단만 바꾼다.

| 조건 | 출력 형식 | 시행 |
|---|---|---|
| **T** | 헤더 TSV, 열 이름 전체, 값 원문 | 라운드 4 SLT 재사용 (t03, t14) |
| **K** | 위와 같되 **헤더의 열 이름을 각각 1글자로 줄여 씀. 매핑은 주지 않는다** | t01, t05 |
| **E** | 열 이름 전체 + **값만 코드표대로 정수화** (`asset_id`·`cpu` 는 원문) | t02, t06 |
| **P** | E 와 같은 코드표, **헤더 줄 없음** (열 순서만 명시) | t03, t07 |

n=2 인 이유: 라운드 1·4·5에서 이 과제류는 조건 내 분산이 0이었다. 아낀 예산을 조건 수로 돌린다
(CLAUDE.md 측정 제약). 다만 라운드 5에서 N=24 JSON 만 분산이 있었으므로 **분산 0을 전제하지 않고
관측해 보고한다**.

### 과제 T12 — 2차 소비자 복원 (A2-H2 / A2-H3 / A2-H5 의 정확도 항)

T11 각 조건의 산출물 1건을 **naive 소비자**에게 주고 질문 6개에 답하게 한다. 소비자는 원본 자산
기록을 보지 못한다. 질문은 전 조건 동일하다.

| 조건 | 소비자가 받는 것 | 시행 |
|---|---|---|
| **UT** | T 산출물만 | t08, t12 |
| **UK** | K 산출물만 (**줄 수 있는 규약이 없다**) | t09, t13 |
| **UE** | E 산출물 + 값 코드표 | t10, t14 |
| **UP** | P 산출물 + 열 순서 + 값 코드표 | t11, t15 |

코드표를 소비자에게 주는 것은 특혜가 아니라 **규약의 일부**다(라운드 4 A6-H6 에서 코드북은
프롬프트에 선언되는 것으로 이미 정의됐다). K 에만 규약이 없는 것은 처치의 결과이지 설계의
불공평이 아니다 — 축약 키를 쓰라고만 하고 매핑을 정의하지 않는 것이 A2-H2 가 말하는 상황이다.

질문 6개와 정답:

| # | 질문 | 정답 |
|---|---|---|
| 1 | AS-2007 의 tier | `large` |
| 2 | AS-2010 의 os | `ubuntu22` |
| 3 | status 가 halted 인 건수 | `5` |
| 4 | region 이 apne1 인 asset_id 전부 | `AS-2001, AS-2005, AS-2011` |
| 5 | cpu 가 16 인 건수 | `3` |
| 6 | env=stage 이고 role=batch 인 asset_id 전부 | `AS-2009` |

### 과제 T13 — 긍정형 간결성 지시 요인 분해 (A1-H4)

라운드 3·4·5와 같은 요청 제한 명세 6항목 설명 문서. 채택된 CK(48자) 를 세 명제로 쪼갠다.

| 조건 | 처치 | 시행 |
|---|---|---|
| **C0** | 없음 | 라운드 4 K0R = 라운드 3 t01·t09·t16 재사용 |
| **CC** | `핵심만 간결히 쓰세요.` (12자) | t16, t20, t24 |
| **CI** | `본문부터 시작해 본문으로 끝내세요.` (19자) — **A1-H4 의 처치** | t17, t21, t25 |
| **CR** | `각 내용은 한 번만 쓰세요.` (15자) | t18, t22, t26 |
| **CK** | 세 줄 전부 (48자) | 라운드 4 K1 = 라운드 3 t04·t10·t15 재사용 |

**바닥 효과 사전 확인** (라운드 6 A5-H5 의 교훈). 기준 조건 C0 의 보존된 산출물 3건을 미리 쟀다.

| 지표 | C0 (t01/t09/t16) | CK (t04/t10/t15) |
|---|---|---|
| `pre` 첫 항목 언급 전 문자 수 (서론 길이) | 202 / 202 / 183 | 94 / 124 / 70 |
| `sumsec` 요약·정리 절 존재 | 3/3 | 0/3 |
| `rep` 6항목 언급 횟수 합 (반복도) | 44 / 49 / 43 | 17 / 18 / 14 |

표적이 기준 조건에 **실재한다**(서론 약 200자, 요약절 3/3). 바닥 효과가 아니므로 실험을 진행한다.
`자평`은 C0 3건에서 관측되지 않았다 → **A1-H4 중 자평 항은 이 과제로 잴 수 없다**고 미리 못박는다.

### 과제 T14 — 긴 프롬프트에서의 지시 위치 (A1-H2)

새 재료: 웹훅 전달 명세 10항목(공통 본문 2,129자). 프롬프트 전체는 지시 없이 **2,418자**로
T13(508자)의 4.8배다 — 이것이 이 라운드의 "긴 프롬프트"의 조작적 정의다.

| 조건 | 지시(CK 48자) 위치 | 시행 |
|---|---|---|
| **WN** | 없음 | t04, t19, t23 |
| **WF** | 프롬프트 **맨 앞**(재료 앞) | t27, t30, t33 |
| **WT** | **맨 끝**(할 일 뒤, 공통 꼬리 앞) | t28, t31, t34 |
| **WB** | 앞과 끝 **둘 다** | t29, t32, t35 |

WF 와 WT 는 프롬프트 길이가 2,468자로 같다. WB 만 2,518자다 — **WB 는 위치가 아니라 용량도
다르다**(지시 2회). 그래서 위치 효과는 WF ↔ WT 로, 반복 효과는 (WF, WT) ↔ WB 로 읽는다.

### 시행 순서

t01–t35 에 조건을 뭉치지 않게 배치했다. T12 는 T11 산출물이 나온 뒤에 돈다.

## 2. 피험자 프롬프트

전 조건 공통 꼬리(조작 변수 아님):
> 도구 호출이 거부되면 다른 수단으로 우회하지 말고, 거부되었다는 사실을 보고하고 중단합니다.

**naive 유지**: 토큰·길이·실험·조건을 언급하지 않는다. 시행 디렉터리는 저장소 밖(scratchpad).
전 시행 동일한 서브에이전트 유형(`general-purpose`)과 모델을 쓴다. 산출물 확장자는 `.txt` 로
통일한다(라운드 1 차단 사건 대책).

| `acc_q` | 소비자 답 6개 중 정답 수 (0–6) — **축 2 정확도 주 지표** | `score_r7.py` |

`L_*` 는 **문자 수이지 토큰이 아니다.** 조건 간 상대 비율로만 해석한다.

`L_report` 를 전 과제에서 함께 잰다 — 라운드 3에서 산출물만 재다가 부호를 반대로 읽은 사건 때문이다.

**커버리지 정규식 수정** (라운드 6에서 확인된 거짓 음성): T13 의 `admin` 항목 패턴에
`적용받지\s*않` 을 추가한다. 라운드 3~5는 전 조건 `cov`=6.0 이라 소급 영향이 없다.
그 밖에 `cov` 가 만점 미만으로 나온 산출물은 **사람이 직접 읽어 거짓 음성 여부를 확인**하고,
거짓 음성이면 감사값을 판정에 쓰고 정규식 결함을 `experiments/raw/r7-incidents.md` 에 남긴다.

## 5. 판정 기준 (실행 후 변경 금지)

**동률 구간**: T11·T12 는 ±2%(분산 0이 예상되는 결정적 과제), T13·T14 는 ±5%.

| 예측 | 채택 조건 | 기각 조건 |
|---|---|---|
| **K1** 키 축약이 줄인다 | `L_out(K) < L_out(T)`, 차이 > 2% | 이하 |
| **K2** 키 축약이 정확도를 깎는다 | `acc_q(UK) < acc_q(UT)` | 같거나 높다 |
| **E1** 코드화가 줄인다 | `L_out(E) < L_out(T)`, 차이 > 2% | 이하 |
| **E2** 코드화의 손실이 키 축약보다 작다 | `acc_q(UE) ≥ acc_q(UK)` | 미만 |
| **P1** positional 이 가장 짧다 | `L_out(P) < L_out(E)` 이고 `L_out(P) < L_out(K)` | 아니면 |
| **P2** positional 의 손실이 가장 크다 | `acc_q(UP) < acc_q(UE)` 이고 `acc_q(UP) ≤ acc_q(UK)` | 아니면 |
| **I1** 서론·맺음말 억제가 줄인다 | `L_file(CI) < L_file(C0)`, 차이 > 5% | 이하 |
| **I2** 품질 유지 | `cov(CI) = 6.0` | 미만 |
| **I3** 표적에 맞았다 | `pre(CI) < pre(C0)` 이고 `sumsec(CI) < sumsec(C0)` | 아니면 **처치가 표적을 안 건드렸다**고 보고 |
| **I4** (산출) 세 명제의 기여 순위 | `L_file` 로 CC·CI·CR 을 정렬 | 판정 대상 아님 |
| **I5** (산출) 하위가산성 | `d(CK)` 대 `Σd_i` (`d_i = L_file(C0) − L_file(조건)`) | 판정 대상 아님 |
| **W1** 지시가 긴 프롬프트에서도 듣는다 | `L_file(WF) < L_file(WN)`, 차이 > 5% | 이하 |
| **W2** 앞+말미가 앞보다 더 줄인다 | `L_file(WB) < L_file(WF)`, 차이 > 5% | 이하 |
| **W3** 위치 효과 | `L_file(WT)` 와 `L_file(WF)` 의 차이 > 5% 이면 위치가 작동 | 5% 이내면 **위치는 무관** |
| **W4** 품질 유지 | `cov` ≥ 9.0 (10항목 중) 전 조건 | 미만인 조건은 그대로 보고 |

판정 매핑:

## 6. 이 라운드가 만들 수 없는 주장

- 절대 토큰 절감률 (proxy 측정)
- **소비자 규약을 바꿨을 때의 결과.** UE·UP 는 코드표를 받고 UK 는 못 받는다. "코드표를 준
  축약 키"는 라운드 4 CB 가 이미 정확도 1.0 을 보였으므로 이 라운드의 K2 를 그 조건으로 확대 해석하지 않는다
- **레코드 수 일반화.** N=12 한 점이다. A2-H8(라운드 5)이 보인 대로 절감률은 N 에 따라 움직인다
- **소비자가 사람일 때.** 소비자는 에이전트다. 라운드 5에서 확인했듯 복호기의 성질이 문턱을 정한다
- **A1-H4 의 자평 항.** 기준 조건에서 자평이 관측되지 않았다 → 표적 부재
- **지시 위치의 일반화.** 프롬프트 2,418자 한 점이다. 더 길면 말미 리마인더가 이길 수도 있다
- 무오염 baseline 대비 절감률 — 피험자가 저장소 `CLAUDE.md` 를 물고 시작하지 않도록 저장소 밖에서
  돌리지만, 모델 자체의 기본 억제 성향은 통제할 수 없다 → 전부 **하한**
