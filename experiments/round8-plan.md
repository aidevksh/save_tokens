작성 시각: 데이터 수집 **전**. §5 판정 기준은 실행 후 변경하지 않는다.

로컬에서 잴 수 있는 미판정 가설이 바닥났다 — 인벤토리의 미판정 18건은 전부 API 나 다중
에이전트 계측기가 먼저 필요하다. 그래서 이번 라운드는 **이미 판정했지만 계측이 막혔던
것들을 다시 연다.** 라운드 6은 바닥 효과로, 라운드 7은 천장 효과로 각각 한 건씩 못 쟀다.
둘 다 원인이 처치가 아니라 **재료**였으므로 재료를 고쳐 다시 잰다.

## 1. 설계

과제 4개, 조건 10개, **신규 30시행**(t01–t30). 프롬프트 전문은 `experiments/prompts/r8-*.txt`,
생성기는 `experiments/scripts/gen_r8.py`. 생성기가 다음을 검증하고 실패하면 파일을 쓰지 않는다.

- T15 세 조건이 출력 형식 문단을 뺀 공통부에서 바이트 동일
- 열 이름 첫 글자가 실제로 충돌한다 (고유 3/8)
- 모든 불투명 열의 값이 **공용 풀 8개** 안에 있고, 값 공간이 완전히 같은 열쌍이 3개 있다
- 열마다 주기가 없다 (라운드 5 LCG 주기 사고 재발 방지)
- 질문 6개가 불투명 열 7개를 정확히 한 번씩 덮는다
- T16 두 조건이 상한 줄만 빼면 `r6-CN300.txt` 와 바이트 동일 → 사다리 연결 성립
- T18 두 조건이 처치 줄만 빼면 바이트 동일, S5 처치 줄이 라운드 6 원문과 동일

### 과제 T15 — 불투명 값 표 (A2-H2 / A2-H5)

12레코드 × 8열. 값은 `k7q m2v p9r t4x w6b z3n c8j h5d` 여덟 개 공용 토큰이고 **어느 열에
있는지 값만 보고는 알 수 없다.**

| 조건 | 처치 | 시행 |
|---|---|---|
| **T** | 헤더 TSV, 열 이름 전체 (기준선) | t01 t04 |
| **K** | 헤더의 열 이름을 각각 1글자로. **매핑은 주지 않는다** | t02 t05 |
| **R** | 헤더 줄 없음. 열 순서는 프롬프트에 있다 | t03 t06 |

2차 소비자가 산출물만 받아 질문 6개에 답한다. 규약은 조건별로 다르고 **그 비대칭이 처치다.**

| 소비자 | 받는 것 | 규약 | 시행 |
|---|---|---|---|
| **UT** | T 산출물 | 없음 (헤더에 이름이 있다) | t07 t10 |
| **UK** | K 산출물 | **없음** — 줄 수 있는 규약 자체가 없다. 약자는 생산자가 지어낸 것이다 | t08 t11 |
| **UR** | R 산출물 | 열 순서 8개 | t09 t12 |

**이 설계가 묻는 것.** 헤더를 지운 R 은 스키마를 **버린 것이 아니라 프롬프트로 옮긴 것**이고,
1글자로 줄인 K 는 복원 규칙 없이 **버린 것**이다. 둘의 출력 길이는 비슷하지만 정보 회계가
다르다 — 이것이 라운드 4 코드북(`R* = 1`)과 같은 계열의 물음이다.

### 과제 T16 — 수치 상한 하향 사다리 (A1-H3 확장)

라운드 3·4·6 과 같은 요청 제한 명세 6항목 → 설명 문서 과제. 상한 줄만 다르다.

| 조건 | 처치 | 시행 | 기존 실측 |
|---|---|---|---|
| C0 | 없음 | (r3 재사용 n=3) | 2,425자 |
| CK | 긍정형 간결성 48자 | (r3 재사용 n=3) | 744자 |
| CN800 | `문서는 800자 이내로 쓰세요.` | (r6 재사용 n=3) | 641자 (상한의 80.1%) |
| CN300 | `문서는 300자 이내로 쓰세요.` | (r6 재사용 n=3) | 248자 (82.6%) |
| **CN150** | `문서는 150자 이내로 쓰세요.` | t13 t15 t17 | — |
| **CN80** | `문서는 80자 이내로 쓰세요.` | t14 t16 t18 | — |

**정보 바닥 참조선 = 93자.** 6항목을 담은 최소 텍스트를 데이터 수집 **전**에 손으로 써서
생성기에 상수로 박아 두었다(`gen_r8.py` `FLOOR_DOC`).

> 버킷 용량 60, 리필 초당 1개. 집계는 IP가 아니라 API 키 단위. 초과하면 429와 Retry-After(초 단위 정수) 헤더. admin 스코프 키는 제외.

이것은 조건이 아니라 **자**다. 150자 상한은 바닥 위, 80자 상한은 바닥 아래다. 따라서
**CN150 은 커버리지를 지키고 CN80 은 못 지켜야 한다.** 이 예측이 빗나가는 두 방향이 모두
정보를 준다 — CN80 이 6/6 이면 참조선이 느슨했던 것이고, CN150 이 무너지면 모델이
바닥보다 훨씬 위에서 이미 항목을 버리기 시작한다는 뜻이다.

### 과제 T17 — 지시의 분산 억제 (A1-H8 신규)

**새 프롬프트를 만들지 않는다.** 라운드 7의 긴 프롬프트(2,418자, 웹훅 명세 10항목)를 그대로 쓴다.

| 조건 | 처치 | 라운드 7 재사용 | 라운드 8 신규 | 합계 |
|---|---|---|---|---|
| **WN** | 지시 없음 | `r7/t04` `r7/t19` `r7/t23` | t19 t21 t23 | n=6 |
| **WT** | 간결성 48자를 **말미**에 | `r7/t28` `r7/t31` `r7/t34` | t20 t22 t24 | n=6 |

라운드 7에서 관측된 것: `L_file` 표준편차가 WN 265.6(평균의 14.4%) 대 WT 68.2(4.1%).
그때는 **사전등록된 예측이 아니었으므로 판정하지 않았다.** 이번에 등록해서 다시 잰다.

**풀링 고지.** 라운드 7 3시행과 라운드 8 3시행을 합쳐 n=6 으로 검정한다. 프롬프트는
바이트 동일하지만 수집 시점이 다르므로 **세션 교란이 있다.** §5 V2 로 라운드 8 내부만의
방향도 따로 본다.

### 과제 T18 — 주석 밀도 규칙 재설계 (A5-H5 재시험)

새 픽스처 `experiments/fixtures/task-d-schedule/` — 영업일·기간 계산 모듈(29줄, 원본 주석 3줄).
테스트 10개 중 **7개가 실패**한 상태에서 시작한다. 구현해야 할 두 함수의 규약이 비자명하다.

- `addBusinessDays` — 시작일은 세지 않는다 / `n=0` 이면 영업일이 아니어도 그대로 / 음수는 역방향
- `mergeRanges` — `[start, end)` 반열림이라 **맞닿은 구간은 합치고** 길이 0 구간은 버린다

| 조건 | 처치 | 시행 |
|---|---|---|
| **DB** | 없음 | t25 t26 (파일럿) + t27 |
| **DS** | `설명은 코드 이름으로 합니다. 주석 없이 읽히게 씁니다.` | t28 t29 t30 |

**파일럿 게이트.** t25·t26 을 먼저 돌려 추가 주석 문자 수를 잰다. **합이 0 이면 t27–t30 을
돌리지 않고 판정 불가로 보고한다** — 라운드 6과 같은 바닥이라는 뜻이고, 시행을 더 쓰는 것은
낭비다. 이 규칙은 라운드 7 이월 사항의 이행이다.

### 시행 순서

t01–t06(T15 생산자) → t07–t12(T15 소비자, 산출물이 나온 뒤 프롬프트 생성) → t13–t18(T16)

## 2. 피험자 프롬프트

- 시행 디렉터리는 **저장소 밖**에 만든다 (`ST_R8_ROOT`, 기본 `%TEMP%/st-r8`).
- 산출물 파일명은 `out.txt` / `doc.txt` / `ans.txt` / `sched.js`. `summary`·`report`·`.md` 를 쓰지 않는다.
- 전 조건 공통 꼬리: `도구 호출이 거부되면 다른 수단으로 우회하지 말고, 거부되었다는 사실을 보고하고 중단합니다.`
- 피험자는 naive 하다. 토큰 절감 실험이라는 사실을 알리지 않는다.
- 오케스트레이터가 피험자의 최종 대화 보고를 `report.txt` 로 기록한다.

## 5. 판정 기준 (실행 후 변경 금지)

동률 구간은 기존 라운드와 같이 **±5%** 로 둔다.

### A2-H2 키 축약 재시험

| 기호 | 조건 |
|---|---|
| M0 | `acc_q(UT)` 평균 ≥ 5.0 — **기준선 천장 가드**. 못 넘기면 M2 를 무효로 하고 판정 불가 |
| M1 | `L_file(K)` < `L_file(T)` |
| M2 | `acc_q(UK)` 평균 ≤ `acc_q(UT)` 평균 − 1.0 |

- M0 ∧ M1 ∧ M2 → **채택** (원 주장 그대로: 줄지만 정확도가 낮아진다)
- M0 ∧ M1 ∧ ¬M2 → **기각(정확도 항)** — 이름 공간이 충돌해도 무손실이라는 더 강한 결론이 되고,
  라운드 7 부분 채택을 여기서 닫는다
- ¬M0 → **판정 불가**

### A2-H5 헤더 제거 재시험

| 기호 | 조건 |
|---|---|
| M4 | `L_file(R)` < `L_file(T)` |
| M5 | `acc_q(UR)` 평균 ≥ `acc_q(UT)` 평균 − 1.0 |

- M0 ∧ M4 ∧ M5 → 원 주장(**"레코드 정확도가 가장 크게 하락한다"**) **기각**,
  길이 항만 남겨 **조건부 채택**으로 갱신
- M0 ∧ M4 ∧ ¬M5 → **채택**
- ¬M0 → **판정 불가**

### A1-H3 수치 상한 하향 (확장)

| 기호 | 조건 |
|---|---|
| E1 | `L_file(CN150)/150` 과 `L_file(CN80)/80` 이 모두 0.70–1.00 |
| E2 | 상한 준수 각 조건 3/3 |
| E3 | `cov(CN150)` = 6.0 **이고** `cov(CN80)` < 6.0 |

- E2 ∧ E3 → **율-왜곡 문턱 관측**. 기법 문서에 "상한의 하한은 정보 바닥"을 추가한다
- E2 ∧ `cov` 둘 다 6.0 → 참조선 93자가 느슨했다는 뜻. **문턱 미관측**으로 보고하고
  다음 라운드에서 상한을 더 내린다
- ¬E2 → 상한이 앵커가 아니라 무시된다는 뜻. A1-H3 **재검토**로 보고한다
- E1 은 앵커 배율(0.8배)의 하향 구간 재현 여부이며 **단독으로 판정을 만들지 않는다**

### A1-H8 지시의 분산 억제 (신규)

`L_file` 의 **자연로그** 분산을 쓴다. 조건 간 평균 길이가 크게 다르므로 원 척도의 분산은
비교할 수 없다.

| 기호 | 조건 |
|---|---|
| V1 | `Var(ln L_file \| WN)` / `Var(ln L_file \| WT)` ≥ **5.050** (단측 F(5,5), α=0.05) — 풀링 n=6 |
| V2 | 라운드 8 내부(각 n=3)에서도 `Var(ln L_file \| WN)` > `Var(ln L_file \| WT)` |

- V1 ∧ V2 → **채택**
- V1 ∧ ¬V2 → **조건부 채택** (풀링에서만 성립 — 세션 교란을 배제하지 못한다)
- ¬V1 → **기각**. 라운드 7 관측은 n=3 의 우연으로 본다

**이 라운드에서 처음 쓰는 검정이다.** 지금까지 이 저장소는 평균만 비교했고 "부호만 신뢰한다"를
반복했다. 분산이 **주** 지표인 가설에서는 분산 비 검정이 가능하므로 여기서만 쓴다. F 검정은
정규성을 가정하며 n=6 에서 그 가정은 검증되지 않는다 — **결과에 이 한계를 병기한다.**

### A5-H5 주석 밀도 규칙 재시험

| 기호 | 조건 |
|---|---|
| P0 | **파일럿 게이트**: t25·t26 의 `cmt_add` 합 > 0 |
| C1 | `cmt_add(DS)` 평균 ≤ `cmt_add(DB)` 평균 × 0.70 |
| C2 | `pass` 가 양 조건 전 시행 10/10 |

- ¬P0 → **판정 불가**(바닥 효과 재발). t27–t30 을 돌리지 않는다.
  라운드 6 기각은 그대로 두고 "두 과제에서 연속으로 바닥"을 사실로 기록한다
- P0 ∧ C1 ∧ C2 → **채택**. 라운드 6 기각을 바닥 효과로 정정한다
- P0 ∧ ¬C1 → **기각 확정**. 표적이 있는데도 안 걷혔다는 뜻이므로 라운드 6보다 강한 기각이다
- P0 ∧ C1 ∧ ¬C2 → **조건부 채택**(품질 손실 동반)

## 6. 이 라운드가 만들 수 없는 주장

- **절대 토큰 절감률.** 전부 문자 수 proxy 다
- **`acc_q` 하락의 크기.** n=2 다. 부호와 "만점이 깨졌는가"까지만
- **정보 바닥 93자의 정확성.** 손으로 쓴 한 개의 최소 텍스트일 뿐 하한의 증명이 아니다.
  더 짧은 표현이 있을 수 있으므로 **93자는 상한으로만 읽는다**
- **분산 억제의 일반화.** 프롬프트 1종(2,418자)·지시 1종(48자)·과제 1종이다
- **F 검정의 정규성.** n=6 으로는 확인할 수 없다
- **주석 규칙의 일반화.** 픽스처 1종이다. 파일럿이 통과해도 "이 과제에서"까지만
- 무오염 baseline 대비 절감률 — 피험자가 저장소 억제 규칙을 물고 시작하므로 전부 **하한**
