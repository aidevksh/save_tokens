# 라운드 2 사전등록 — 부분 재생성의 손익분기

작성 시각: 데이터 수집 **전**. §6 판정 기준은 실행 후 변경하지 않는다.

라운드 1에서 "unified diff가 전체 재출력보다 22.3% 길었다"는 기각 결과가 나왔다. 이것은 diff가 나쁘다는 뜻이 아니라 **N=30에서는 졌다**는 뜻이다. 라운드 2는 손익분기가 실재하는지, 계산식이 맞는지를 본다.

## 1. 가설

### R2-H1 — 파일 길이 역전
파일 길이 `N`이 손익분기 `N*`를 넘으면 unified diff가 전체 재출력보다 짧아진다. `m`(변경 줄)과 `k`(hunk 수)를 고정하고 `N`만 바꾸면 부호가 뒤집힌다.

### R2-H2 — 컨텍스트 줄이 손익분기를 이동시킨다
컨텍스트를 3줄에서 1줄로 줄이면 `N*`가 내려가, N=30에서도 diff가 전체 재출력을 이긴다.

### R2-H3 — H/q 결합 (라운드 1 확인 사실의 재검)
오버헤드 `H`를 줄이면 적용 실패율 `q`가 오른다. 컨텍스트 1줄 조건에서 적용 실패·hunk 분열이 더 자주 발생한다.

**계산식**: `N* ≈ 2m + C_total + k + 2` (m=변경 줄, C_total=총 컨텍스트 줄, k=hunk 수)
- C=3, m=6, k=3 → `N* ≈ 12 + 18 + 3 + 2 = 35`
- C=1, m=6, k=3 → `N* ≈ 12 + 6 + 3 + 2 = 23`

## 2. 설계

**교란 통제**: 두 피처는 변경 요청 6건이 의미적으로 **동일**하다(replicas / env / logging.level / logging.format / autoscale.enabled / database.ssl). `m=6`, `k=3`(C=3 기준)도 동일. 변하는 것은 `N`뿐이다.

| 피처 | N | m | k (C=3) | 파일 |
|---|---|---|---|---|
| F30 | 30 | 6 | 3 | `data/02-deploy-original.yaml` (라운드 1 재사용 → 복제 검증) |
| F120 | 120 | 6 | 3 | `data/r2-deploy120-original.yaml` (신규) |

### 조건 6개 × n=2 = 12시행

| 조건 | 피처 | 출력 형식 | 시행 |
|---|---|---|---|
| A30 | F30 | 파일 전체 재출력 | t01, t08 |
| B30 | F30 | unified diff (컨텍스트 지시 없음) | t02, t12 |
| C30 | F30 | unified diff (컨텍스트 1줄 지시) | t03, t10 |
| A120 | F120 | 파일 전체 재출력 | t04, t11 |
| B120 | F120 | unified diff (컨텍스트 지시 없음) | t05, t09 |
| C120 | F120 | unified diff (컨텍스트 1줄 지시) | t06, t07 |

시행 순서는 조건이 뭉치지 않게 배치했다. `n=2`는 라운드 1 교훈(결정적 과제는 조건 내 분산 0)에 따른 **결정성 파일럿 겸용**이다. 두 시행이 바이트 동일하면 "n=2, 조건 내 분산 0"으로 병기 보고하고 n을 늘리지 않는다.

### 기준선 — 이상적 방출기 (사전 계산, `git diff`)

에이전트 출력은 이 값보다 짧을 수 없다. 차이가 **방출 오버헤드**다.

| | 전체 재출력 | diff C=3 | diff C=1 |
|---|---|---|---|
| F30 | 510 B | 690 B (+35.3%) | 501 B (−1.8%) |
| F120 | 2,469 B | 883 B (−64.2%) | 615 B (−75.1%) |

부수 관측: F120은 C=1에서 hunk가 3개→**5개**로 분열한다. `k`는 `C`에 의존한다 — 계산식이 `k`를 상수로 두는 것은 근사다.

## 3. 피험자 프롬프트

전문은 `experiments/prompts/r2-*.txt`. 조건 간 차이는 **출력 형식 지시 한 문단뿐**이며 나머지는 바이트 동일하다.

공통 삽입 (라운드 1b 교훈 선반영, 조건 A/B/C 동일 → 조작 변수 아님):
> 도구 호출이 거부되면 다른 수단으로 우회하지 말고, 거부되었다는 사실을 보고하고 중단한다.

산출물 확장자는 `.yaml` / `.diff`. 파일명에 `summary`·`report`를 쓰지 않는다.

**naive 유지**: 피험자에게 토큰·길이·실험·조건을 언급하지 않는다. 시행 디렉터리는 저장소 밖(`scratchpad/st-r2/`)에 두어 정답 키와 프로젝트 규약 노출을 막는다.

## 4. 종속 변수

| 기호 | 정의 | 측정 |
|---|---|---|
| `L` | 산출물 문자 수 **(proxy)** | `tools/measure.py --json` |
| `q` | 적용 실패 | `git apply -p1` → 실패 시 `-p0`, `--recount` 순차 시도 |
| `X` | 최종 파일이 기대 결과와 완전 일치 | 바이트 비교 |
| `k_obs` | 실제 방출된 hunk 수 | `@@` 카운트 |
| `C_obs` | hunk 당 실제 컨텍스트 줄 수 | 파싱 |
| `H` | 방출 오버헤드 = (L − 기준선) / 기준선 | 계산 |

`L`은 **문자 수이지 토큰이 아니다.** 조건 간 상대 비율로만 해석한다. 전 조건 산출물이 영문 YAML/diff이므로 언어 구성은 자동으로 고정된다.

## 5. 품질 게이트

게이트를 통과하지 못한 시행은 길이 집계에서 **제외**한다. 짧지만 틀린 산출물이 이기는 것을 막는다.

| 게이트 | 내용 |
|---|---|
| Q1 | 지정 경로에 산출물 존재, 크기 > 0 |
| Q2 | 형식 준수 — A: 전체 N줄·생략 표기 없음 / B·C: `--- a/` `+++ b/` `@@` 헤더 존재 |
| Q3 | B·C: `git apply` 성공 (A는 해당 없음, 자동 통과) |
| Q4 | 적용 결과가 기대 파일과 완전 일치 |
| Q5 | 요청 6건 전부 반영 |
| Q6 | 부수 손상 0줄 |

Q3 실패는 **무효가 아니라 데이터**다 — `q`는 R2-H3의 종속 변수다. Q3 실패 시행은 `q` 집계에 넣고 `L` 집계에서 뺀다.

무효 사유는 Q1 실패(산출물 미생성)뿐이다. 조건별 무효 건수를 반드시 보고한다.

## 6. 판정 기준 (실행 후 변경 금지)

동률 구간: 조건 간 차이가 **±3% 이내**면 "차이 없음"으로 판정한다.

| 예측 | 채택 조건 | 기각 조건 |
|---|---|---|
| **P1** 복제 | F30에서 `L(B30) > L(A30)`, 차이 > 3% | `L(B30) < L(A30)`, 차이 > 3% |
| **P2** 역전 | F120에서 `L(B120) < L(A120)`, 절감 **≥ 40%** | 절감 < 40% |
| **P3** 컨텍스트 효과 | `L(C) < L(B)` 가 **양쪽 N 모두**에서, 차이 > 3% | 어느 한쪽에서 `L(C) ≥ L(B)` |
| **P4** 교차점 | F30에서 `L(C30) ≤ L(A30)` (동률 포함) | `L(C30) > L(A30)`, 차이 > 3% |
| **P5** H/q 결합 | C 조건의 Q3 실패 또는 `k_obs` 분열이 B 조건보다 많다 | C 조건 실패 ≤ B 조건 실패 |

**R2-H1 채택 = P1 ∧ P2.** 둘 중 하나라도 기각이면 H1 기각.
**R2-H2 채택 = P3 ∧ P4.** P3만 성립하면 "부분 채택 — 컨텍스트 축소는 diff를 줄이지만 교차점을 N=30까지 끌어내리지는 못한다".
**R2-H3 채택 = P5.**

조건당 유효 시행이 2건 미만이면 그 조건이 관여하는 예측은 **판정 불가**다. 판정 불가를 채택으로 바꿔 쓰지 않는다.

**기법 승격 조건**: P2 채택 시에만 `techniques/` 에 문서를 만든다. 문서에는 반드시 **적용 조건(손익분기)**을 명시한다 — "diff를 써라"가 아니라 "N > N* 일 때 diff를 써라".

## 7. 이 라운드가 만들 수 없는 주장

- 절대 토큰 절감률 (proxy 측정)
- YAML 외 파일 형식으로의 일반화 (단일 형식만 시험)
- 실제 코딩 에이전트 워크플로에서의 절감 (합성 과제)
- `N*`의 정확한 값 — N을 2점(30, 120)만 잡았다. **부호 역전의 존재**는 보일 수 있어도 교차 지점은 구간으로만 말한다
- `m`, `k`가 다른 경우로의 외삽 (둘 다 고정했다)
